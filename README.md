# 🍳 TEAMねぎまの台所

### 人間ひとりとAIたちの、にぎやかな料理帖。

**TEAMねぎまの台所**は、クロイヌ本舗が運営する、家庭料理のレシピサイトです。

日々の食卓で実際に作っている料理を、人間とAIたちが協力して、楽しく、使いやすいレシピにまとめています。

砂糖を使わず素材の甘みを生かした料理、毎日のお弁当、家にある材料で作るおかずなど、飾らない家庭料理が中心です。

## 🥕 このサイトでできること

レシピを読むだけでなく、実際の調理中に使えることを大切にしています。

- **スマートフォン対応** — 台所でスマホを見ながら調理できます。
- **調理タイマー** — レシピ内のタイマーで調理時間を確認できます。
- **手順チェック** — 完了した工程をタップして、調理の進み具合を確認できます。
- **印刷対応** — 紙のレシピカードとしても利用できます。
